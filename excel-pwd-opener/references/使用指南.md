# 密码表格自动打开 · 使用指南

这是一个小工具：**给加密的 Excel/WPS 表格记住密码，以后双击就自动开锁**，不用再手打密码。

---

## 一、怎么拿到它

只有一个文件：`opener.exe`。不用装运行库，不用解压一堆东西，复制到哪台电脑都能用。

> 注意：程序只对**当前这个 Windows 账户**生效。换账户要重新装一次（每个账户的密码是各自独立加密保存的）。

> 打包里还有一个 `opener-cli.exe`，那是给写脚本 / 自动化的人用的命令行版本，
> 普通使用**完全不需要**它。相关说明见 `CLI使用指南.md`。

## 二、怎么装（1 步）

1. 把 `opener.exe` 放到桌面或任意文件夹；
2. **双击它**。

程序会自动完成安装：

- 把程序本身复制到 `%LOCALAPPDATA%\ExcelAutoOpener\`（用户目录，不写系统盘、不弹管理员权限窗口）；
- 在**开始菜单**添加「密码表格自动打开」的入口；
- 接管 `.xlsx` / `.xls` / `.xlsm` 的**默认打开方式**；
- 在「设置 → 应用 → 已安装的应用」里登记一条，方便以后卸载。

装好后程序会直接打开**设置窗口**，这就进入了下一步。

> 首次双击加密表格时，Windows 可能弹出「你要如何打开这个文件？」——选「密码表格自动打开」，并勾选「始终使用此应用」。这一步做一次就行。

## 三、怎么用（最常用的两件事）

### 1）给一个表格记住密码

在设置窗口里：

1. 点「**浏览…**」选中要自动打开的加密表格；
2. 填「**打开密码**」（就是平时双击表格要输的那个）；
3. 如果这个表格还有**编辑密码**（只读打开后想改内容时要输的），在同一个界面里一并填上；
4. 「双击这个表格时」选 **只读打开** 或 **可编辑打开**；
5. 点「**保存**」。

**「保存」是瞬时的**——它只把这条记录记下来，**不会打开表格**，所以可以一条接一条地连续录入，不会每录一条就等一次。

想核对密码对不对，再点「**测试这条密码**」。测试**只核对密码本身对不对，不需要把表格打开**：

- 显示「密码验证通过」——放心用；
- 显示「打开密码不正确」/「编辑密码不正确」——马上改，不会等到用时才发现。

> **保存和测试是分开的**：确定密码没错，就只点「保存」，不必测试；只是拿不太准、或想复查时，才点测试。这样批量录入时不必每条都等一次。

> 测试绝大多数情况下是**离线核对**（直接读表格里记着的密码校验信息），毫秒级完成、
> **完全不会启动 WPS/Excel**，也不会占用文件，所以点了立刻就有结果。
> 只有极少数「编辑密码藏在加密内容里」的表，才会短暂启动一次办公软件来补验。
>
> 测「编辑密码」时要注意：只有**确实设过「修改权限密码」**的表格才谈得上对错。如果表格本身
> 没有设这个密码，程序会如实告诉你「没有设置编辑密码、你填的用不上」，而不是含糊地报「通过」。

### 2）以后打开表格

什么都不用按，**双击表格**即可：程序自动填密码打开。

| 你的操作 | 效果 |
| --- | --- |
| 双击表格 | 按你在设置里选的「只读 / 可编辑」打开 |
| 按住 `Shift` 再双击 | 这次按**可编辑**打开（临时代替设置） |
| 右键 → **编辑** | 按**可编辑**打开 |
| 按住 `Ctrl` 再双击 | **不会打开**，这是 Windows 的「多选」操作，不是程序的问题 |

> 如果按住 `Ctrl` 后松开才双击，那实际上就是普通双击，会按设置的方式打开。

## 四、设置窗口各部分是干什么的

- **打开密码 / 编辑密码**：在同一个界面里分别填两把密码（打开密码 + 编辑密码）；「显示」复选框可以在看不清时把密码显示成明文（默认是圆点）。
- **双击这个表格时**：只读打开 = 安全、不会误改；可编辑打开 = 像正常打开一样能改内容（需要填了编辑密码）。
- **保存**：只把记录写进密码库，**不打开表格**，瞬间完成、可连续录入。
- **测试这条密码**：把当前输入的这条密码打开表格核对一次（几秒钟），不修改密码库。
- **测试全部记录**：把已保存的每条记录都验一遍，适合过一段时间复查。
- **清空输入**：把上面几个输入框清掉，便于录下一个表格。
- **已保存的表格**列表：
  - 第 1 列「双击可编辑」的**方框**可勾选/取消 = 改变这个表格双击时的打开方式；
  - **双击某一行** = 把它的路径和密码载回上面，方便修改后重新保存；
  - **点中整行**（可按住 `Ctrl`/`Shift` 选多条）= 选中要删除的对象，再点「删除所选记录」。
- **删除所选记录**：把选中的记录从密码库里删掉——删的是「密码库里的这条记录」，**不是磁盘上的表格文件**。
- **接管文件关联（安装）** / **还原关联（卸载）**：手动重装或撤销文件关联。
- **办公软件**：选 WPS 还是 Excel 来打开。选错了也没关系——测试时程序会自动纠正成能用的那个。

## 五、怎么卸载

两种方式，任选其一：

- **设置 → 应用 → 已安装的应用**，找到「密码表格自动打开」，点卸载；
- 或者再双击一次 `opener.exe`（**升级/重装**），在设置窗口点「**还原关联（卸载）**」。

卸载会还原文件关联、删除开始菜单快捷方式。**你保存的密码不会被删除**，如需彻底清除，手动删除 `%APPDATA%\ExcelAutoOpener` 文件夹即可（路径可以在地址栏粘贴这个字符串打开）。

## 六、常见问题

**Q：为什么我按住 Ctrl 双击打不开？**
因为 Windows 把「按住 Ctrl + 单击」当成多选文件。要临时编辑打开，请用 `Shift + 双击`，或右键 → 编辑。

**Q：装的时候为什么没弹「管理员权限」？**
故意这样的。程序只写你自己账户下的目录和注册表，不需要管理员权限，也不会弹 UAC。

**Q：为什么设置窗口里「测试」有时说「未能验证」？**
这类表（比如整体加密、又另设了编辑密码）需要临时启动一次办公软件补验，如果套件没装好、
或表格正被别的窗口占用，就会「未能验证」。密码本身没问题，稍后再点一次「测试这条密码」即可。

**Q：为什么提示「这个表格没有设置编辑密码，你填的编辑密码在这份文件里用不上」？**
说明这份表格**压根没设「修改权限密码」**。不是说你的密码错，而是这类表本来就没有东西可供
比对——它的编辑权限是靠别的方式管的，或者干脆没限制。这种情况下编辑密码填不填都不影响打开。
如果你的原意是想核对「修改权限密码」，请换一个确实设过该密码的表格来测。

**Q：测试为什么这么快、而且没看到 WPS/Excel 起来？**
0.1.2 起测试默认走**离线核对**：密码对不对，表格文件里本来就记着答案，程序直接读出来比对，
不用打开文件。所以又快又稳，也不会因为文件被占用而误判。

**Q：录了很多表格，每条都要点「测试」吗？**
不用。「保存」是瞬时的、不会打开表格；确定密码正确就不必测试，可以一条接一条地保存。想复查时再点「测试这条密码」或「测试全部记录」。

**Q：保存时怎么确认密码没输错？**
如果只是心里没底，点一下「测试这条密码」即可当场核对；确定没错就省掉这一步，直接保存。

**Q：换电脑 / 换账户后还要重设吗？**
要。密码是按账户加密保存的（Windows DPAPI），换账户后读不到，需要在新账户里重装并重录一次。

**Q：资源管理器偶尔假死或重启，跟这个有关吗？**
已针对这个做了处理：安装时会把 Office 的「表格预览/缩略图」按用户关掉（表格预览用处不大，但它处理加密文件时可能让资源管理器崩溃）。如果还有异常，可在设置窗口点「还原关联（卸载）」后反馈。
